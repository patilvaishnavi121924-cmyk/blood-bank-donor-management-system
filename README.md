# 🩸 Blood Bank and Donor Management System

A web-based Blood Bank and Donor Management System developed using PHP, MySQL, HTML, CSS, JavaScript, and Bootstrap.

## 📌 Project Overview

The Blood Bank and Donor Management System is designed to simplify the management of blood donors, blood availability, blood requests, and administrative operations.

The system provides a centralized platform where administrators can manage donor information and blood stock efficiently.

## ✨ Features

- 👤 User Registration and Login
- 🩸 Blood Donor Management
- 🔍 Search Blood Availability
- 📋 Blood Request Management
- 🏥 Blood Stock Management
- 👨‍💼 Admin Dashboard
- 🔐 Authentication System
- 📊 Donor and Blood Records
- 📱 Responsive User Interface
- 🗄️ MySQL Database Integration

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- PHP
- MySQL
- XAMPP
- AdminLTE
